# Экспорт и импорт: какие файлы нужны

Форматов два — для договоров и для плана закупок (тендеров). Они устроены
по-разному, потому что решают разные задачи.

Общее для обоих:

- формат файла — **`.xlsx`** (Excel 2007 и новее). Старый `.xls`, `.csv`
  и Google Sheets напрямую не принимаются: сохраните через
  «Файл → Сохранить как → Книга Excel (.xlsx)».
- читается **только первый лист** книги;
- **первая строка — заголовки**, данные со второй;
- колонки распознаются **по названию, а не по порядку** — их можно менять
  местами, лишние колонки игнорируются;
- пустые строки пропускаются.

Самый надёжный способ получить правильный файл — **сначала выгрузить**
существующие данные, открыть выгрузку в Excel и править её. Тогда заголовки
заведомо совпадут.

## Договоры

Кнопки на странице «Договоры». Файл выгрузки — `contracts.xlsx`, лист «Договоры».

### Колонки

| Колонка | Обязательна | Что содержит |
|---|---|---|
| `number` | **да** | Номер договора. Это ключ: если такой номер уже есть — запись обновится, если нет — создастся |
| `customer` | нет | Название заказчика. Если такого нет в справочнике, он будет создан автоматически |
| `title` | нет | Краткое название, до 255 символов |
| `status` | нет | Код статуса, см. таблицу ниже. Неизвестное значение игнорируется, статус останется прежним |
| `amount` | нет | Сумма договора, число. Без пробелов и знака ₸ |
| `signed_date` | нет | Дата подписания |
| `deadline` | нет | Срок исполнения |
| `specification` | нет | Тех. спецификация, обычный текст любой длины |
| `paid_amount` | — | Только в выгрузке. При импорте **игнорируется**: оплата считается по графику платежей |

Названия колонок пишутся латиницей и в нижнем регистре. Регистр и пробелы
по краям система приводит сама, так что `Number` и ` number ` тоже подойдут.

### Коды статусов

| Код | Что означает |
|---|---|
| `new` | Новый |
| `negotiation` | Согласование |
| `in_progress` | В работе |
| `closed` | Закрыт |
| `cancelled` | Отменён |

В файле должен стоять именно код (`in_progress`), а не русское название
(«В работе») — иначе строка импортируется, но статус не изменится.

### Даты

Принимаются два вида:

- ячейка с **форматом даты** в Excel — предпочтительно;
- **текст вида `2026-09-15`** (год-месяц-день).

Формат `15.09.2026` текстом не распознается. Если Excel сам превратил ваш ввод
в дату — всё в порядке, так и надо.

### Пример минимального файла

| number | customer | title | amount | deadline |
|---|---|---|---|---|
| 2026-014 | ГКП Больница №2 | Халаты медицинские | 450000 | 2026-09-15 |

### Что вернёт система

```json
{"created": 1, "updated": 0, "errors": []}
```

`created` — сколько создано, `updated` — сколько обновлено, `errors` — список
проблемных строк с номерами. Строки без номера договора молча пропускаются.

> **Импорт обновляет существующие договоры.** Совпадение идёт по номеру, и если
> в файле окажется номер уже существующего договора, его поля будут перезаписаны
> значениями из файла. Перед загрузкой большого файла имеет смысл выгрузить
> текущие данные — это готовый откат.

## План закупок (тендеры)

Кнопки на странице «Тендеры / План закупок». Файл выгрузки — `tenders.xlsx`,
лист «план закупок».

Здесь заголовки **на русском**, потому что формат повторяет рабочую таблицу
заказчика, чтобы её можно было загружать как есть.

### Колонки

| Колонка | Что содержит |
|---|---|
| Площадка | Название торговой площадки |
| Номер закупки | Номер закупки |
| Номер лота | Номер лота |
| От какой фирмы | Ваша компания-участник |
| Организация | Заказчик |
| Наименование товара | Предмет закупки |
| Дата окончания | Дата окончания приёма заявок |
| Время окончания | Время окончания |
| Срок поставки | Дней на поставку |
| Кол-во | Количество |
| Цена заказчика | Цена за единицу от заказчика |
| Сумма заказчика | Сумма по лоту |
| План цена | Ваша плановая цена |
| Себестоимость за ед. | Себестоимость единицы |
| Себес общий | Себестоимость по лоту |
| План сумма | Плановая сумма |
| Прибыль | Расчётная прибыль |
| Маржа % | Расчётная маржа |
| Статус | Статус лота |
| Решение | Решение по участию |
| Ответственный | Логин менеджера |

### Импорт терпимее, чем у договоров

Колонки ищутся **по вхождению слова** в заголовок, а не по точному совпадению.
Это сделано намеренно: в рабочих файлах заголовки приходят с опечатками
и лишними словами. Система понимает варианты:

- «Дата окончание» и «Дата окончания»
- «Время окончаня» (с опечаткой) и «Время окончания»
- «От какой фирмы» и «С какой фирмы»
- «Наименование товара» и «Предмет закупки»
- «Время поставки» и «Срок поставки»

Если заголовок первой колонки повреждён или пуст, она всё равно считается
площадкой — так устроено под конкретный рабочий файл.

## Частые ошибки

| Симптом | Причина |
|---|---|
| «Файл не передан» | Файл прикреплён не в то поле. Пользуйтесь кнопкой на странице, а не запросом вручную |
| Импорт прошёл, но записей ноль | Пустая колонка `number` (для договоров). Строки без номера пропускаются молча |
| Даты съехали или не заполнились | Дата записана как `15.09.2026` текстом. Нужен либо формат даты Excel, либо текст `2026-09-15` |
| Статус не поменялся | В файле русское название вместо кода. Нужен `in_progress`, а не «В работе» |
| Суммы не импортировались | В ячейке текст с пробелами или знаком валюты: `450 000 ₸`. Нужно число `450000` |
| Ошибка при открытии файла | Файл сохранён как `.xls` или `.csv`. Пересохраните в `.xlsx` |
| Заказчик задвоился | В файле название написано иначе, чем в справочнике («ТОО Ромашка» и «ТОО "Ромашка"»). Совпадение идёт по точному названию |

## Права доступа

Выгружать может любой, у кого есть доступ к разделу на чтение. Загружать —
только те, у кого есть право записи: администратор, менеджер, бухгалтер
(для договоров).
