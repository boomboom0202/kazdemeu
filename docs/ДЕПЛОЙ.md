# Публикация КазДемеу ERP в интернете (бесплатно)

Схема: **один сервис на Render** (Docker: Django отдаёт и API, и собранный React)
+ **база PostgreSQL в Neon**. Обе площадки бесплатные и без карты.

Результат — постоянная ссылка вида `https://kazdemeu-erp.onrender.com`,
работает, даже когда ваш компьютер выключен.

---

## Шаг 1. Загрузить код на GitHub

Аккаунт: https://github.com/signup (если ещё нет).

Создайте пустой репозиторий: https://github.com/new
- Name: `kazdemeu-erp`
- **Private** (код бизнес-логики лучше не открывать)
- Не ставьте галочки «Add README / .gitignore / license»

Затем в папке проекта (PowerShell):

```powershell
cd C:\Users\abyla\Desktop\atelier-erp
git remote add origin https://github.com/ВАШ_ЛОГИН/kazdemeu-erp.git
git branch -M main
git push -u origin main
```

Git попросит войти — откроется окно браузера, подтвердите вход в GitHub.

---

## Шаг 2. Создать бесплатную базу в Neon

1. https://neon.tech → Sign up (можно через GitHub).
2. Create project: имя `kazdemeu`, регион **Europe (Frankfurt)** — ближе всего к Казахстану.
3. На экране проекта нажмите **Connect** → скопируйте строку **Connection string**
   вида:
   ```
   postgresql://user:пароль@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
   Сохраните её — понадобится на следующем шаге.

Бесплатный тариф Neon: 0.5 ГБ данных — для ERP-демо этого хватает с большим запасом.
База не удаляется по времени (в отличие от бесплатной базы самого Render, которая
живёт 30 дней), поэтому берём именно Neon.

---

## Шаг 3. Развернуть на Render

1. https://render.com → Sign up через GitHub.
2. **New → Web Service** → Connect repository → выберите `kazdemeu-erp`.
   Render сам увидит `render.yaml` и `Dockerfile`, менять настройки не нужно.
3. Проверьте, что выбрано: Language/Runtime **Docker**, Instance Type **Free**,
   Region **Frankfurt**.
4. В разделе **Environment Variables** заполните:

   | Переменная | Значение |
   |---|---|
   | `DATABASE_URL` | строка подключения из Neon (шаг 2) |
   | `ANTHROPIC_API_KEY` | ключ для ИИ-ассистента, можно оставить пустым |

   Остальные (`DJANGO_SECRET_KEY`, `DJANGO_DEBUG`, `SEED_DEMO`, `WEB_CONCURRENCY`)
   подставятся из `render.yaml` автоматически.
5. **Create Web Service**. Первая сборка идёт 5–10 минут.

Готово. Ссылка появится вверху страницы сервиса.
При старте автоматически выполняются миграции и `seed_demo`, поэтому сразу
работают демо-входы: `admin` / `admin12345`, а также `aigerim`, `saule`,
`marat`, `bolat` с паролем `demo12345`.

**Сразу после первого входа смените пароль admin** — стенд доступен всему интернету.

---

## Шаг 4. Убрать «засыпание» (по желанию)

Бесплатный сервис Render засыпает после 15 минут без запросов, и первый заход
после сна грузится 30–60 секунд. Перед показом заказчику либо откройте ссылку
за минуту до начала, либо настройте бесплатный пинг:

1. https://uptimerobot.com → Sign up (бесплатно).
2. Add New Monitor → HTTP(s) → URL вашего сервиса → интервал **5 минут**.

Тогда сервис не засыпает и открывается мгновенно.

## Что важно знать про бесплатный тариф

| Тема | Как есть сейчас |
|---|---|
| Данные | Хранятся в Neon, переживают перезапуски и обновления кода |
| Загруженные файлы (сканы договоров) | **Теряются при перезапуске** — у бесплатного Render нет постоянного диска. Для демонстрации это обычно не мешает; если нужно надёжно — подключаем S3-совместимое хранилище (Cloudflare R2, 10 ГБ бесплатно) |
| Засыпание | Через 15 мин простоя; лечится пингом (шаг 4) |
| Мощность | 512 МБ RAM, 0.1 CPU — для демо и небольшой команды хватает |
| Свой домен (например erp.kazdemeu.kz) | Render поддерживает на бесплатном тарифе: Settings → Custom Domain |
| Трафик | 100 ГБ в месяц |
