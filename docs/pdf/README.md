# Инструкции по ролям

Готовые PDF и их исходники. Снимки экрана внутри HTML встроены как data-URI,
поэтому файлы самодостаточны — их можно открыть или переслать как есть.

| Файл | Роль | Страниц |
|---|---|---|
| `КазДемеу-Кладовщик.pdf` | Кладовщик | 7 |
| `КазДемеу-Технолог.pdf` | Технолог | 6 |

## Как пересобрать PDF

Снимки и печать делаются headless-браузером на сервере — панель браузера
локально не отдаёт кадры.

```
scp docs/pdf/*.html docs/pdf/собрать-pdf.mjs user@open-test.ektu.kz:~/shots/pdf/
ssh user@open-test.ektu.kz
cd ~/shots && sudo docker run --rm -v /home/user/shots:/shots -w /shots \
  mcr.microsoft.com/playwright:v1.55.0-noble node собрать-pdf.mjs
```

Сценарии съёмки экранов лежат там же на сервере: `~/shots/shots.mjs` (кладовщик)
и `~/shots/shots-tech.mjs` (технолог). Чтобы снять другую роль, поменяйте в них
логин и список экранов.
