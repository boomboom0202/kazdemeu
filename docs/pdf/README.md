# Инструкции

Готовые PDF и их исходники. Снимки экрана встроены в HTML как data-URI,
поэтому файлы самодостаточны — их можно открыть или переслать как есть.
Все снимки сделаны в живой системе под учётными записями этих ролей.

## С чего начинать

**`КазДемеу-Ввод-в-эксплуатацию.pdf`** (22 страницы) — порядок первого
запуска: кто входит первым, что нажимает и почему именно в такой
последовательности. Снята на пустой базе, шаг за шагом: администратор
заводит сотрудников → кладовщик оприходует материалы → технолог
описывает изделие → бухгалтер вносит постоянные расходы → менеджер
заводит договор → цех выполняет заказ → директор видит цифры.
В конце — работа с Excel (загрузка плана закупок и договоров, повторные
загрузки, частые ошибки), переход с прежнего учёта, когда история уже
накоплена, и раздел «мелким шрифтом»: поведения, которые срабатывают
сами и удивляют, если о них не знать. Читать её нужно до инструкций
по ролям.

Форматы файлов Excel подробно расписаны в [`../ЭКСПОРТ-ИМПОРТ.md`](../ЭКСПОРТ-ИМПОРТ.md),
а перенос накопленной истории — в [`../ПЕРЕХОД-С-ПРЕЖНЕГО-УЧЁТА.md`](../ПЕРЕХОД-С-ПРЕЖНЕГО-УЧЁТА.md).

## Как пересобрать

Снимки и печать делаются headless-браузером на сервере: панель браузера
локально не отдаёт кадры, обычный скриншот снять нечем.

```
# 1. снять экраны (правьте список ролей и экранов внутри)
scp shots-all.mjs user@open-test.ektu.kz:~/shots/
ssh user@open-test.ektu.kz 'cd ~/shots && sudo docker run --rm -v /home/user/shots:/shots \
  -w /shots mcr.microsoft.com/playwright:v1.55.0-noble node shots-all.mjs'

# 2. собрать HTML из шаблона (текст инструкций живёт здесь)
python собрать-инструкции.py

# 3. напечатать в PDF
scp *.html собрать-pdf.mjs user@open-test.ektu.kz:~/shots/pdf/
ssh user@open-test.ektu.kz 'cd ~/shots && sudo docker run --rm -v /home/user/shots:/shots \
  -w /shots mcr.microsoft.com/playwright:v1.55.0-noble node собрать-pdf.mjs'
```

`собрать-инструкции.py` содержит и шаблон, и текст всех инструкций —
править содержание нужно там, а не в готовых HTML. Оформление общее,
в `shared.css`. Обратите внимание: сборщик пишет промежуточные
`manual-<роль>.html`, их нужно скопировать в файлы с русскими именами.

Инструкция по вводу в эксплуатацию собирается отдельно —
`собрать-запуск.py`, снимки берутся из папки `golive` (или из пути
в переменной `GOLIVE_SHOTS`). Сценарии съёмки, которые заодно служат
сквозным тестом всей цепочки, лежат на сервере: `golive-ui.mjs`
(шаги 1–4) и `golive-ui2.mjs` (шаги 5–8). Перед съёмкой базу нужно
очистить: `python manage.py wipe_data --yes-i-am-sure --users`.

Сценарии съёмки лежат на сервере в `~/shots/`: `shots.mjs` (кладовщик),
`shots-tech.mjs` (технолог), `shots-all.mjs` (остальные четыре).
