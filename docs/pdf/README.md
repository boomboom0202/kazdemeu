# Руководство

**`КазДемеу-Руководство.pdf`** — как работать в системе: тендер → договор →
цех → склад → финансы. Одно руководство на все роли: в каждом разделе
сказано, кто что вносит и что система считает сама, а в разделе «Роли и права» —
кому что открыто. Снимки сделаны в живой системе на таблицах заказчика:
«Договора.xlsx», «Расходы.xlsx», «Расход административные.xlsx» и листах
«цех отчёт».

Разделы: как устроена система · тендер · реестр договоров · деньги договора ·
загрузка «Расходы.xlsx» · запуск в цех · цех и этапы · листы этапов (крой,
пошив, штучные) · заказ «размер × этап» · настройка этапов и бригады ·
склад · финансы и административные расходы · аналитика · роли и права ·
что стало с прежними данными · что происходит само.

HTML-версия (`КазДемеу-Руководство.html`) самодостаточна: снимки встроены,
её можно открыть в браузере или переслать как есть.

## Образцы Excel

Папка `образцы` — файлы в тех форматах, которые система принимает; из них же
в руководстве нарисованы листы Excel:

| Файл | Куда загружать |
|---|---|
| `План-закупок-пример.xlsx` | Тендеры → «Импорт из Excel» |
| `Реестр-договоров-пример.xlsx` | Договоры → «Импорт «Договора.xlsx»» |
| `Расходы-пример.xlsx` | Договоры → «Импорт «Расходы.xlsx»» (с выбором договора для каждой колонки) |
| `Расход-административные-пример.xlsx` | Финансы → Административные расходы → «Импорт» |

## Как пересобрать

Нужны работающая система с данными (локально или на сервере), Node с
`playwright-core` и установленный Chrome (путь — переменная `CHROME`).

```
# 1. снимки — в папку guide; логин администратора: SHOTS_USER / SHOTS_PASSWORD
node guide-shots.mjs guide <папка с таблицами заказчика> http://127.0.0.1:8011

# 2. HTML — текст руководства живёт в собрать-руководство.py
python собрать-руководство.py

# 3. PDF
node печать-pdf.mjs КазДемеу-Руководство.html КазДемеу-Руководство.pdf
```

Сценарий снимков заодно проверяет, что все экраны открываются без ошибок:
в конце он печатает список снятого и ошибки страницы, если они были.
Оформление — `shared.css`.
